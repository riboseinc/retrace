= retrace v2 (historical note)

The contents previously in this file described an early, beta-era
version of what was then called "retrace v2". The Autotools build
commands, the `retrace2` libnereon-based wrapper, and the per-action
parameter names listed here are all outdated.

The current, authoritative documentation is in link:README.adoc[].

What this file got right (and is now in the main README):

* JSON-driven configuration via `RETRACE_JSON_CONFIG`.
* The action system: `log_params`, `call_real`, `modify_in_param_str`,
  `modify_in_param_int`, `modify_in_param_arr`,
  `modify_return_value_int`, `memory_fuzz`.
* `getenv` redirect and `malloc` fuzz examples.

What this file got wrong (superseded):

* Build system is CMake, not Autotools.
* Library is `libretrace.so` / `.dylib` / `.dll`, not `libretrace_v2.so`.
* The `retrace2` libnereon wrapper was never finished; use
  `LD_PRELOAD` / `DYLD_INSERT_LIBRARIES` directly.
* v1 source was removed at v2.1.0 (ADR-0011) -- "v2 vs v1" is no
  longer a choice users need to make.
