retrace

Userspace libc interceptor
SEE · CONTROL · BREAK

The only tool that observes, modifies, AND breaks libc calls — without code, without recompiling, on every platform.

Get started GitHub →
$ curl -sSL https://raw.githubusercontent.com/riboseinc/retrace/main/scripts/install.sh | sh

One command. No config files.

🔍

Trace

See every libc call with args, return values, and timing.

$ retrace trace malloc,free -- /bin/ls
  malloc  → 0x7f8e2a  (<1µs)
  free    → 0         (<1µs)
  ...
  1247 calls, 48.3ms total
💣

Fuzz

Inject OOM, short I/O, latency. Find error-path bugs in seconds.

$ retrace fuzz malloc --rate 0.1 -- ./server
(crash — you found an OOM bug)
🎮

Mock

Make any function return whatever you want.

$ retrace mock getuid 0 -- ./check-root
welcome, root
🛡

Sandbox

Block file access by path deny-list at runtime.

$ retrace run --config sandbox.json -- ./app
sandbox: DENIED '/etc/shadow'
📊

HTML viewer

Interactive trace page. No Python, no git clone.

$ retrace trace --html -- ./server
wrote /tmp/retrace-12345.html
🐶

Docker

Add tracing to any container in one line.

RUN curl -sSL .../libretrace-linux-x86_64.so \
    -o /usr/lib/libretrace.so
